# 31 — General Resources (Roadmaps y referencias externas)

> Recursos externos que complementan el handbook y el Engineering-OS. No reemplazan los estándares
> internos — son referencias para consultar cuando se necesita una visión amplia de un rol técnico,
> una ruta de aprendizaje o una guía de referencia rápida.
>
> Priorización: P0 = recursos críticos que todo dev del ecosistema debería conocer; P1 = útiles
> para temas específicos; P2 = referencia secundaria.

## Roadmaps generales

| # | Recurso | Prioridad | Rating | Para qué sirve |
|---|---|---|---|---|
| 1 | [roadmap.sh](https://roadmap.sh) | P0 — Prioritario | ⭐⭐⭐⭐⭐ | Roadmaps visuales mantenidos por la comunidad para Frontend, Backend, DevOps, React, TypeScript, System Design, API Design, Cloudflare, AI, QA, Ciberseguridad y ~60+ roles/skills más. Cada roadmap tiene pasos, recursos y proyectos sugeridos. Útil como check-list de "lo que un rol X debería saber" antes de profundizar en un tema. |
