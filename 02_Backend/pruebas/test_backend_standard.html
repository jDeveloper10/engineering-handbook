Formato de respuesta API

Helper único para toda respuesta HTTP — sin JSON.stringify repetido.

REQUIRED

Construir respuesta

Contrato compartido con el frontend:
{ success: true, data } ó { success: false, error: { code, message } }

Respuesta generada

HTTP 200
// Presiona un botón ←

✓ Nunca JSON.stringify(body) + headers repetidos — ese patrón está en los 13 workers actuales como deuda técnica.

src/lib/response.ts 
function jsonResponse(body, status, corsHeaders) {
  return new Response(JSON.stringify(body), {
    status,
    headers: { "Content-Type": "application/json", ...corsHeaders },
  });
}

// ✓ Todos los workers usan estos dos helpers, nunca JSON.stringify a mano
export const ok   = (data, cors) => jsonResponse({ success: true,  data }, 200, cors);
export const fail = (code, msg, status, cors) =>
  jsonResponse({ success: false, error: { code, message: msg } }, status, cors);

Autenticación — middleware único

requireAuth() reutilizado en cada handler que necesite auth.

REQUIRED

Simulador de token

src/middleware/auth.ts 
export async function requireAuth(req, env) {
  const header = req.headers.get("Authorization");

  if (!header?.startsWith("Bearer "))
    return { success: false, errorResponse: fail("UNAUTHORIZED", ...) };

  const token = header.replace("Bearer ", "");
  const supabase = createClient(env.SUPABASE_URL, env.SERVICE_KEY);
  const { data: { user }, error } = await supabase.auth.getUser(token);

  if (error || !user)
    return { success: false, errorResponse: fail("UNAUTHORIZED", ...) };

  return { success: true, context: { user, supabase } };
}

import { z } from "zod";

const createExampleSchema = z.object({
  title:       z.string().min(3, "El título debe tener al menos 3 caracteres.").max(100),
  description: z.string().max(500).optional().default(""),
});

// Mismo schema que usa el frontend — mismo contrato, sin traducción en el medio
const parsed = createExampleSchema.safeParse(body);
if (!parsed.success) {
  const msg = parsed.error.issues.map(i => i.message).join(" ");
  return fail("VALIDATION_ERROR", msg, 400, corsHeaders);
}

Manejo de errores

Códigos estables para el frontend, mensajes en español, nunca stack traces al cliente.

REQUIRED
UNAUTHORIZED HTTP 401

Token inválido, ausente o expirado.

msg: "No autorizado."
VALIDATION_ERROR HTTP 400

msg: "El título debe tener al menos 3..."

Recurso o ruta no existe.

Logging estructurado

Objeto JSON, nunca string concatenado. Secretos nunca se loguean.

REQUIRED

Generar log de ejemplo

src/lib/logger.ts
export const logger = {
  info: (event, ctx?) =>
    console.log(JSON.stringify({
      level: "info", event, ...ctx,
      timestamp: new Date().toISOString(),
    })),

  error: (event, err?, ctx?) => {
    // ✓ Token truncado — nunca completo en logs
    const safe = err instanceof Error ? err.message : String(err);
    console.error(JSON.stringify({
      level: "error", event, error: safe, ...ctx,
      timestamp: new Date().toISOString(),
    }));
  }
};

Rate Limiting

Todo endpoint público sin auth previa debe tener un límite de tasa.

REQUIRED

Simulador — límite 5 req/10 seg

0
requests en ventana actual
0Límite: 5
Ventana activa por 10 segundos tras el primer request.
Patrón — contador en KV
async function checkRateLimit(ip, env) {
  const key   = `rl:${ip}`;
  const count = parseInt((await env.KV.get(key)) ?? "0");

  if (count >= 5)
    return fail("RATE_LIMITED", "Demasiadas solicitudes.", 429);

  // Incr con TTL de ventana (10 s) — idempotente
  await env.KV.put(key, String(count + 1), { expirationTtl: 10 });
  return null; // ok, continuar
}

Webhooks — firma + idempotencia

Verificar firma antes de procesar. El mismo evento dos veces no debe tener doble efecto.

REQUIRED

Verificar firma HMAC

Patrón idempotente
// 1. Verificar firma HMAC antes de procesar
const sig = request.headers.get("X-Signature");
const expected = await hmac(env.WEBHOOK_SECRET, body);
if (!timingSafeEqual(sig, expected))
  return fail("UNAUTHORIZED", "Firma inválida.", 401);

// 2. Idempotencia con KV — mismo event_id = no-op
const already = await env.KV.get(`processed:${payload.event_id}`);
if (already) return ok({ status: "already_processed" });

// 3. Ack inmediato — procesamiento pesado en Queue
ctx.waitUntil(processAsync(payload, env));
